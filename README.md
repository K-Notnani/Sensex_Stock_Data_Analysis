# Sensex Stock Data Analysis

##  Overview

This project analyzes historical stock market data using Python and the yfinance library. It focuses on the BSE Sensex index and selected Indian companies to study stock price trends, moving averages, daily returns, and volatility through data visualization.

---

##  Features

- Download historical stock market data using yfinance
- Data cleaning and preprocessing
- Daily returns calculation
- Moving Average (MA) analysis
- Volatility analysis
- Data visualization using Matplotlib
- Comparative analysis of multiple stocks

---

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
